# Daily Career Tip (Python)

A tiny command-line career coach that randomly chooses one tip from a single
list of 20 encouragement quotes and practical career tips. It uses only the
Python standard library and does not need a browser, server, or internet
connection.

## Run it

Open a terminal in this folder and run:

```text
python career_tip.py
```

Each run prints a bordered card with the heading, today's date, category, tip,
and author when the quote has one.

## Sample output

This output was captured from a run of the script; the selected tip will vary
each run:

```text
+------------------------------------------------------------------+
| DAILY CAREER COACH                                                |
| Friday, October 16, 2026                                          |
| Category: Practical Advice                                        |
|                                                                    |
| Take time to document your achievements weekly. It makes         |
| performance reviews much easier.                                 |

```

The examples are intended for encouragement and learning, not as professional
career advice.
