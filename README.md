# Career Ghana Task

A collection of my internship projects. The Python Development tasks are the career tools below, plus my earlier frontend projects.

## Python Development Intern Tasks

### 1. Career Quiz CLI Tool (`1_career_quiz_cli`)
A command-line quiz with 10 multiple-choice questions about interests and work style. Each answer scores one of four profiles (Tech, Business, Creative, Social), and the quiz prints a recommended career path at the end.

Run it:
```
python career_quiz.py
```
Tools: Python only (no extra libraries).

### 3. Career Path Predictor: Your First ML Model
A beginner machine learning model that predicts a career profile from 10 self-rated statements (1 to 5), using a Decision Tree trained on a small dataset I created.

- `3_career_predictor_python`: command-line version with a plain-language write-up of how the model works.
- `3_career_predictor_web`: the same model with a browser quiz.

Run the Python version:
```
pip install -r requirements.txt
python career_predictor.py
```
Tools: Python, pandas, scikit-learn. The dataset is small, so predictions are a fun starting point, not a real career assessment.

### 5. Daily Career Tip Generator
Shows a random career tip or motivational quote with a formatted box, the date, and a category.

- `5_daily_career_tip_python`: command-line version (optional email bonus, off by default).
- `5_daily_career_tip_web`: a web version with a category filter, Tip of the Day, Share Tip button and light/dark mode. Open `index.html` in your browser.

Run the Python version:
```
python career_tip.py
```
