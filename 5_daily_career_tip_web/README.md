# Daily Career Tip (Web)

A standalone career-coach page with 20 encouragement quotes and practical
career tips. It includes a date-based Tip of the Day, mixed random mode,
category filtering, a Share Tip menu, and a light/dark theme toggle. The page uses
only plain HTML, CSS, and JavaScript; it does not need a server or internet
connection.

## Open the page

Double-click `index.html` to open it in your browser. Keep `index.html`,
`style.css`, `script.js`, and `tips.js` together in this folder.

In Tip of the Day mode, the selected tip is based on today's local date. Random
mode selects from the currently selected category (or the full mixed list when
All is selected) and avoids showing the same tip twice in a row.
